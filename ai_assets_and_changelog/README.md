โฟลเดอร์ `ai_assets_and_changelog/` นี้รวบรวม **เอกสารสรุปสิ่งที่พัฒนาและแก้ไขทั้งหมด**, **ไฟล์คลิปวิดีโอทดสอบ**, และ **ไฟล์โมเดล AI (YOLOv4-tiny Darknet สำหรับ CiRA CORE)** ไว้ในที่เดียว เพื่อให้สามารถนำโปรเจกต์ไปติดตั้งหรือเปิดดูรายละเอียดย้อนหลังได้ครบถ้วน

## 2. สรุปสิ่งที่แก้ไขและพัฒนาทั้งหมด (Changelog)

### 2.1 ด้าน AI Pipeline & โปรเจกต์ CiRA CORE (`cira_core_bridge/` และ `lopo.npj`)
1. **ออกแบบสถาปัตยกรรม 2-Stage Person-ROI แก้ปัญหากล้องวงจรปิดมุมกว้าง:**
   - เดิมการรันโมเดลชั้นเดียวบนภาพมุมกว้าง (Wide-angle CCTV) มองไม่เห็นมวนบุหรี่ที่มีขนาดเล็กเพียงไม่กี่พิกเซล
   - แก้ไขโดยให้ **Stage 1 (`person_coco`)** ตรวจจับตัวบุคคลทั้งหมดก่อน จากนั้นโหนด **`cira_person_crop_node.py` (Stage 1.5)** ครอปเฉพาะบริเวณครึ่งตัวบน/ใบหน้า/มือ ส่งต่อให้ **Stage 2 (`smoking_evidence`)** ตรวจหามวนบุหรี่และกลุ่มควันในความละเอียดสูง แล้วจึงแปลงพิกัดกลับสู่ภาพเต็มใน **`cira_webhook_node.py` (Stage 2.5)**
2. **แก้ไขพิกัดกรอบ Bounding Box ให้ตรงตำแหน่งจริง 100%:**
   - โหนด `DeepDetect` ของ CiRA CORE ส่งค่าพิกัด `(x, y)` ออกมาเป็นจุดกึ่งกลางวัตถุ `(center_x, center_y)` ในขณะที่ OpenCV วาดกรอบจากมุมซ้ายบน `(left_x, top_y)`
   - แก้ไขสมการแปลงพิกัด `left_x = x - w/2` และ `top_y = y - h/2` ทั้งในขั้นตอนครอปบุคคลและขั้นตอนวาดกรอบหลักฐาน ทำให้กรอบสีเขียว (`person`), กรอบสีแดง (`smoke`) และกรอบสีส้ม (`cigarette`) ตรงตัวคนและกลุ่มควันอย่างแม่นยำ
3. **ระบบวิเคราะห์ควันพ่นระดับศีรษะ (`Exhaled Smoke-Plume Analyzer`):**
   - เพิ่มอัลกอริทึมตรวจจับการเปลี่ยนแปลงความสว่างและความอิ่มตัวสีของกลุ่มควันจางๆ เฉพาะโซนระดับศีรษะ/ปาก (`top_y` ถึง `top_y + 26%` ของความสูงคน) พร้อมทำ **Person Masking** ตัดพื้นที่ของคนที่เดินผ่านด้านหลังออกทั้งหมด เพื่อป้องกันไม่ให้ตรวจจับคนเดินผ่านเป็นกลุ่มควัน
4. **ระบบกรองการแจ้งเตือนผิดพลาดบนกล้องเว็บแคม (Anti-Hallucination):**
   - ป้องกันอาการจับผิดตอนยกแก้วดูดน้ำหรือถือของ: หาก `person_coco` พบ `cup`, `bottle`, `wine glass` หรือ `cell phone` และไม่มีกลุ่มควันจริง ระบบจะกดไม่ให้แจ้งเตือนมวนบุหรี่ปลอมทันที
   - ตัดกรอบแนวตั้งลักษณะคล้ายหลอดดูดน้ำ (`height > width * 1.9`) และบังคับตำแหน่งต้องอยู่ในโซนใบหน้า/มือของบุคคลเท่านั้น
   - กรองเฟรมที่ภาพเบลอจากการขยับมือเร็วด้วยค่าความคมชัด (`Laplacian Variance >= 28`) และบังคับตรวจพบต่อเนื่องหลายเฟรม (`Temporal Consensus`) ก่อนส่งแจ้งเตือน
5. **แก้ปัญหาโหนด `WebCam` ค้างใน CiRA CORE และรองรับการเปิดกล้องพร้อมหน้าเว็บ:**
   - สร้าง **Shared Camera Broker (`webcam_daemon.py` พอร์ต `3099`)** เปิดกล้องผ่าน `cv2.CAP_DSHOW` (หลีกเลี่ยงบั๊กไดรเวอร์ MSMF ที่ทำให้ CiRA CORE ค้าง) และสร้างโหนดรับภาพ `cira_webcam_source_node.py` ในแถวที่ 3 ของ `lopo.npj`
   - ทำให้สามารถเปิดดูกล้องสดบนหน้าเว็บ Dashboard และรันโหนด Webcam ใน CiRA CORE พร้อมกันได้โดยไม่ฟ้อง Camera Busy และใช้โควตาโมเดลพอดีลิมิต `AI Model: 4/4`

### 2.2 ด้านระบบหลังบ้าน Backend (`backend/`)
1. **ระบบจัดเก็บและเสิร์ฟภาพหลักฐานจริง (`Evidence Image Storage`):**
   - อัปเกรด `/api/webhook/detection` ให้รองรับ `evidence_base64` แปลงบันทึกเป็นไฟล์ `.jpg` ลงโฟลเดอร์ `backend/evidence/` และเปิด Static Route `/evidence` ให้หน้าเว็บแสดงภาพหลักฐานได้ทันที
2. **ระบบสตรีมกล้องเว็บแคมสด MJPEG แยกเธรดความเร็วสูง:**
   - เพิ่ม `webcamRoutes.js` (`/api/webcam/stream`, `/api/webcam/status`, `/api/webcam/stop`) และ `webcamAiService.js` เชื่อมต่อกับเอนจิน CUDA Python แบบตรวจสอบพอร์ตอัตโนมัติ ไม่เกิดปัญหาโปรเซสชนกันเมื่อเซิร์ฟเวอร์รีสตาร์ท
3. **นำระบบบังคับเบลอใบหน้าออกทั้งหมด:**
   - ปรับทั้งฝั่ง AI Bridge, Backend (`detectionService.js`) และ Frontend ให้แสดงภาพหลักฐานต้นฉบับคมชัดพร้อมกรอบตรวจจับโดยไม่เบลอใบหน้าตามความต้องการของผู้ใช้งาน
4. **เพิ่ม API รีเซ็ตข้อมูลเดโม่ (`POST /api/detections/reset`):**
   - รองรับการล้างรายการทดสอบและไฟล์ภาพชั่วคราวเพื่อเริ่มต้นนำเสนอใหม่ได้สะดวก

### 2.3 ด้านส่วนติดต่อผู้ใช้ Frontend (`frontend/`)
1. **ปรับปรุง UI ภาษาไทยเต็มรูปแบบและอัตลักษณ์ มหาวิทยาลัยศรีปทุม (SPU):**
   - แปลข้อความ เมนู ตาราง กราฟ และสถานะทุกหน้าเป็นภาษาไทย ใช้ฟอนต์ **Prompt** และเพิ่มโลโก้ **SPU (`spu-logo.png`)** บนแถบเมนูด้านซ้าย ส่วนหัวเว็บ และไอคอนแท็บเบราว์เซอร์
2. **เพิ่มหน้ากล้องเว็บแคม (`/webcam` — `LiveWebcam.jsx`):**
   - แสดงภาพสตรีมสดพร้อมกรอบตรวจจับแบบเรียลไทม์ แสดงค่า FPS สถานะการพบบุคคล สวิตช์เปิด-ปิดการบันทึกอัตโนมัติ และรายการเหตุการณ์ที่บันทึกในรอบปัจจุบัน
3. **อัปเกรดหน้าภาพรวมระบบ (`/`), ประวัติการตรวจจับ (`/logs`) และสถิติ (`/statistics`):**
   - เพิ่มระบบค้นหา กรองตามจุดติดตั้งกล้อง กรองตามสถานะเกณฑ์ยืนยัน (`ผ่านเกณฑ์ยืนยัน` / `รอตรวจสอบเพิ่มเติม`) และปุ่มส่งออกรายงาน **CSV ภาษาไทย (UTF-8 BOM)** เปิดใน Excel ได้ภาษาไม่เพี้ยน
   - ปรับปุ่มล้างข้อมูลเริ่มเดโม่เป็นระบบยืนยัน 2 ขั้นตอน ป้องกันการเผลอกดลบข้อมูลโดยไม่ตั้งใจ
   - ปรับแต่งรายละเอียด UI ตามคอมเมนต์ตรวจสอบทั้งหมด (ตัดบรรทัดสถานะ LINE ในหน้าต่างหลักฐาน และตัดข้อความส่วนเกินในหน้าเว็บแคมและภาพรวมระบบให้กระชับสะอาดตา)
