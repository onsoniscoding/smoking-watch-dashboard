# สรุปรายการแก้ไขโปรเจกต์ คลิปวิดีโอทดสอบ และโมเดล AI ทั้งหมด (Smoke Watch × CiRA CORE)

โฟลเดอร์ `ai_assets_and_changelog/` นี้รวบรวม **เอกสารสรุปสิ่งที่พัฒนาและแก้ไขทั้งหมด**, **ไฟล์คลิปวิดีโอทดสอบ**, และ **ไฟล์โมเดล AI (YOLOv4-tiny Darknet สำหรับ CiRA CORE)** ไว้ในที่เดียว เพื่อให้สามารถนำโปรเจกต์ไปติดตั้งหรือเปิดดูรายละเอียดย้อนหลังได้ครบถ้วน

## 2. สรุปสิ่งที่แก้ไขและพัฒนาทั้งหมด (Changelog)

### 2.1 ด้าน AI Pipeline & โปรเจกต์ CiRA CORE (`cira_core_bridge/` และ `lopo.npj`)
1. **สถาปัตยกรรม 2-Stage Person-ROI & Dual-Scale Cropping:**
   - **ในเส้น Flow วิดีโอของ `lopo.npj`:** ให้ **Stage 1 (`person_coco`)** ตรวจจับตัวบุคคลและวัตถุตัวหลอกก่อน จากนั้นโหนด **`cira_person_crop_node.py` (Stage 1.5)** ครอปเฉพาะบริเวณครึ่งตัวบน/ศีรษะ/มือ ส่งต่อให้ **Stage 2 (`smoking_evidence`)** ตรวจหามวนบุหรี่และกลุ่มควัน แล้วแปลงพิกัดกลับสู่ภาพเต็มใน **`cira_webhook_node.py` (Stage 2.5)**
   - **ในเอนจิน `run_smoking_ai.py` (`run_two_stage_inference`):** ครอปตรวจสอบ **2 ระยะ (Dual-Scale)** คือ 1) ครอปครึ่งตัวบนรวมช่วงมือและกลุ่มควัน และ 2) ครอปซูมแน่นบริเวณศีรษะ/ปากเพื่อขยายขนาดมวนบุหรี่ขนาดเล็ก (พร้อม fallback ตรวจภาพเต็มเมื่อไม่พบในภาพครอป) แล้วรวมกรอบที่ซ้อนทับกันด้วย `nms_dedup()`
2. **แก้ไขพิกัดกรอบ Bounding Box ให้ตรงตำแหน่งจริง 100%:**
   - โหนด `DeepDetect` ของ CiRA CORE ส่งค่าพิกัด `(x, y)` ออกมาเป็นจุดกึ่งกลางวัตถุ `(center_x, center_y)` จึงแปลงเป็นมุมซ้ายบน `left_x = x - w/2` และ `top_y = y - h/2` ทั้งในขั้นตอนครอปและวาดกรอบ ทำให้กรอบสีเขียว (`person`), สีแดง (`smoke`) และสีส้ม (`cigarette`) ตรงตำแหน่งจริง
3. **ระบบวิเคราะห์ควันพ่นระดับศีรษะ (`Exhaled Smoke-Plume Analyzer`):**
   - วิเคราะห์กลุ่มควันจางๆ เฉพาะโซนระดับศีรษะ/ปาก (`top_y` ถึง `top_y + 26%` ของความสูงคน) พร้อมทำ **Person Masking** ตัดพื้นที่ของคนที่เดินผ่านด้านหลังออกทั้งหมด
4. **ระบบเว็บแคมใช้ 2 โมเดล CUDA ประหยัด VRAM และแชร์ข้อมูลตัวหลอกให้ CiRA CORE ตลอดเวลา:**
   - `webcam_daemon.py` โหลดเฉพาะ **2 โมเดลหลัก (`person_coco` + `smoking_evidence`)** ใช้ VRAM เพียง `~517 MiB` เพื่อรันควบคู่กับ CiRA CORE (`AI Model: 4/4`) บนการ์ดจอ 4 GB ได้เสถียรที่ความเร็วสตรีมใช้งานจริงประมาณ **`~7.4 FPS`**
   - แม้ไม่ได้เปิดหน้าเว็บ `/webcam` ทิ้งไว้ เมื่อโหนด `cira_webcam_source_node.py` ใน `lopo.npj` ดึงภาพจากพอร์ต `3099/raw_frame` ตัว Broker จะรัน `person_coco` ส่งพิกัดคนและตัวหลอก (`cup`, `bottle`, `wine glass`, `cell phone`) ให้แถว Webcam ใน CiRA CORE ครอปซูมตัวคนและกรองแก้วน้ำได้ครบเหมือนหน้าเว็บ
5. **มาตรฐานเกณฑ์ยืนยันหลายเฟรม (`Temporal Consensus`) ที่ตรงกันทั้งระบบ:**
   - **กล้องโถงทางเดิน CCTV (`corridor`):** หากความมั่นใจสูง `>= 78%` แจ้งเตือนได้ทันทีใน `1` เฟรม หากต่ำกว่า `78%` ต้องพบต่อเนื่อง **`2` เฟรม** (`MIN_TEMPORAL_HITS = 2`)
   - **กล้องเว็บแคม (`webcam` — ทั้งบนหน้าเว็บและแถว Webcam ใน `lopo.npj`):** บังคับตรวจพบต่อเนื่องครบ **`4` เฟรม** (`MIN_TEMPORAL_HITS = 4` ที่ความถี่ AI ~4 ครั้ง/วินาที) และข้ามเฟรมภาพเบลอ (`Laplacian < 28`) เสมอ
   - **โหมดทดสอบภาพนิ่ง (`image_test`):** ใช้ `1` เฟรม (`MIN_TEMPORAL_HITS = 1`, `COOLDOWN_SEC = 0`)

### 2.2 ด้านระบบหลังบ้าน Backend (`backend/`)
1. **ระบบจัดเก็บและเสิร์ฟภาพหลักฐานจริง (`Evidence Image Storage`):**
   - รองรับ `evidence_base64` บันทึกเป็นไฟล์ `.jpg` ลงโฟลเดอร์ `backend/evidence/` และเปิด Static Route `/evidence`
2. **ระบบสตรีมกล้องเว็บแคมสด MJPEG (`webcamRoutes.js` / `webcamAiService.js`):**
   - เชื่อมต่อพอร์ต `3099` แบบตรวจสอบโปรเซสเดิมอัตโนมัติ ไม่เกิดปัญหาพอร์ตชนกันเมื่อเซิร์ฟเวอร์รีสตาร์ท
3. **API ตรวจสอบยืนยัน / ลบรายการ (`PATCH /api/detections/:eventId/review`) และรีเซ็ตเดโม่ (`DELETE /api/detections/reset`):**
   - รองรับผู้ดูแลระบบกดยืนยันเหตุการณ์ที่รอตรวจสอบเพิ่มเติม หรือกดลบรายการที่ AI จับผิดออกจากระบบทันที

### 2.3 ด้านส่วนติดต่อผู้ใช้ Frontend (`frontend/`)
1. **UI ภาษาไทยเต็มรูปแบบและอัตลักษณ์ มหาวิทยาลัยศรีปทุม (SPU):**
   - แปลทุกหน้าเป็นภาษาไทย ใช้ฟอนต์ **Prompt** และแสดงโลโก้ **SPU (`spu-logo.png`)**
2. **หน้ากล้องเว็บแคม (`/webcam` — `LiveWebcam.jsx`):**
   - สตรีมภาพสด MJPEG แสดงค่า FPS จริง สถานะการพบบุคคล และรายการเหตุการณ์ที่บันทึกในรอบปัจจุบัน
3. **หน้าภาพรวมระบบ (`/`), ประวัติการตรวจจับ (`/logs`) และสถิติ (`/statistics`):**
   - มีปุ่มกด **`ยืนยัน`** และ **`ลบ`** สำหรับรายการที่ขึ้น `รอตรวจสอบเพิ่มเติม` ทั้งบนตารางและในหน้าต่างดูหลักฐาน (`EvidenceModal.jsx`) พร้อมส่งออกไฟล์รายงาน **CSV ภาษาไทย (UTF-8 BOM)**
